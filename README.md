# دریافت محصولات ووکامرس (WooCommerce Product Fetcher)

ابزار تک‌صفحه‌ای PHP برای دریافت لیست محصولات هر فروشگاه وردپرس/ووکامرس از طریق **Store API**، نمایش جدولی با صفحه‌بندی، انتخاب فیلدها و خروجی JSON / Excel.

> نتایج **روی سرور ذخیره نمی‌شوند** — فقط در مرورگر کاربر نگه داشته می‌شوند.

---
لینک مشاهده دمو
https://storage-web.ct.ws/

## ویژگی‌ها

- ورود آدرس دامنه فروشگاه (مثال: `yoursite.com`)
- انتخاب فیلدهای مورد نیاز با تیک
- دریافت صفحه‌به‌صفحه با **نوار پیشرفت درصدی** (AJAX)
- جدول با صفحه‌بندی و تعداد ردیف قابل تنظیم
- خروجی **JSON** و **Excel (xlsx)**
- پشتیبانی از تصاویر، دسته‌بندی‌ها، ویژگی‌ها (attributes)، برچسب‌ها و …
- رابط کاربری فارسی و راست‌چین

---

## فیلدهای قابل انتخاب

| کلید | عنوان فارسی |
|------|-------------|
| `id` | شناسه |
| `name` | نام محصول |
| `slug` | اسلاگ |
| `permalink` | لینک محصول |
| `sku` | کد کالا (SKU) |
| `short_description` | توضیحات کوتاه |
| `description` | توضیحات کامل |
| `price` | قیمت |
| `regular_price` | قیمت عادی |
| `sale_price` | قیمت فروش ویژه |
| `currency` | واحد پول |
| `currency_minor_unit` | واحد فرعی پول |
| `on_sale` | در حراج |
| `average_rating` | میانگین امتیاز |
| `review_count` | تعداد نظرات |
| `is_in_stock` | موجودی |
| `is_purchasable` | قابل خرید |
| `images` | تصاویر |
| `categories` | دسته‌بندی‌ها |
| `attributes` | ویژگی‌ها (کامل) |
| `attributes_flat` | جدول ویژگی‌ها (نام / مقدار) — معادل جدول «اطلاعات بیشتر» صفحه محصول |
| `tags` | برچسب‌ها |

> **نکته قیمت:** در Store API قیمت‌ها معمولاً بر حسب کوچک‌ترین واحد پول (مثلاً ریال یا سنت) برمی‌گردند. فیلد `currency_minor_unit` تعداد رقم اعشار را مشخص می‌کند.

## پیش‌نیازها

- PHP 7.4+ (توصیه: 8.x)
- افزونه **cURL** فعال
- فروشگاه هدف باید ووکامرس داشته باشد و endpoint زیر در دسترس باشد:

```text
https://YOUR-SITE.com/wp-json/wc/store/v1/products
```

---

## نصب سریع

1. فایل `index.php` را در ریشه یک هاست PHP آپلود کنید.
2. آدرس را در مرورگر باز کنید.
3. دامنه فروشگاه را وارد کنید و «شروع دریافت محصولات» را بزنید.

نیازی به دیتابیس یا نصب جداگانه نیست.

---

## اجرای محلی

```bash
# با PHP built-in server
php -S localhost:8080
```

سپس به `http://localhost:8080` بروید.

## نحوه کار

1. مرورگر درخواست را به همان `index.php` می‌فرستد (اکشن `fetch_page`).
2. PHP به‌عنوان پروکسی به Store API فروشگاه درخواست می‌زند (مشکل CORS پیش نمی‌آید).
3. هدرهای `X-WP-Total` و `X-WP-TotalPages` برای پیشرفت خوانده می‌شوند.
4. محصولات تمیز و فقط با فیلدهای انتخاب‌شده برمی‌گردند.
5. فرانت‌اند در حافظه مرورگر جمع می‌کند، جدول می‌سازد و امکان خروجی می‌دهد.

---

## محدودیت‌ها

- فقط endpoint عمومی Store API (`wc/store/v1`) — نیازی به کلید API ووکامرس نیست.
- اگر سایت هدف API را بسته باشد یا فایروال/کلودفلر جلوی درخواست سرور را بگیرد، دریافت ممکن است ناموفق شود.
- تصاویر به‌صورت URL در جدول و خروجی قرار می‌گیرند (فایل تصویر دانلود و embed نمی‌شود).
